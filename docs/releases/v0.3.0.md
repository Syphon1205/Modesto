# Modesto v0.3.0 — Early Modesto

This is a **new Modesto** early release — not production 1.0.

Expect rough edges, unfinished surfaces, and fast iteration. The previous “1.0.0 / Work is here” story is superseded: Code + Work exist, but the product is not ready to claim a 1.0 line.

## Product shape

- **Code** — coding workspace for projects, agents, diffs, terminals, and Git.
- **Work** — early cowork surface for local tasks, sessions, Connections, browser, and artifacts. Still evolving.

## Highlights

- **Honest versioning** — shipped as `0.3.0` because Modesto is not production-ready 1.0.
- **Code and Work** — two places to work with agents; Work is early, not “done.”
- **Work shell** — shared Code-style sidebar, Connections as its own tab, Automations as a sidebar tab.
- **Chat reliability** — Temporary no longer deletes chats after a successful send; hung Work sends surface a recoverable error instead of silent limbo.

## Notes

- Existing projects, threads, and credentials are preserved.
- Old `/research` bookmarks still redirect to Work.
- Treat this build as an early preview for people who want the new Modesto shape — not a stable production desktop.
