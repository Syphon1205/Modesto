# Modesto v0.1.4 — San Leandro

Compact composer chrome, durable handoff checkpoints, and agent controls that match what you actually have enabled.

## Highlights

- **Composer bubbles** — Changes `+N/−M`, Commit & Push, `N Working`, `N/M tasks`, Plan mode, and Multi-agent as Cursor-style pills above the chat. They only appear when useful; todos no longer take the whole composer stack.
- **Durable agent checkpoints** — Provider handoffs snapshot the working tree into hidden `refs/modesto/agent-checkpoints/…` refs. Inspect or roll back from the seam card without inventing scratch branches.
- **Handoff seam polish** — Structured Done / Incomplete / Next notes, live-repo-first bootstrap, destination continue / return on the seam card, and default summaries from the latest assistant message.
- **Claude agents end-to-end** — Selected Claude agents and launch args survive drafts and dispatch; the Traits picker treats Claude like Kilo/OpenCode when runtime agents exist.
- **Cloud Agents gating** — OpenClaw “Allowed coding agents” only offers providers enabled on the server (disabled-but-already-allowed stay visible so you can uncheck them).
- **Builds on Fremont (v0.1.3)** — Continuity handoffs, Cursor-parity settings, and structured continue / return flows remain the foundation for this release.

## In-app update feeds

`latest-mac.yml`, `latest.yml`, `modesto-mac.yml`, and `modesto.yml` are **electron-updater metadata**, not installers. The desktop app uses them to detect and download the matching architecture build. End users should download the `.dmg` / `.exe` installers above, not the YAML files.

macOS auto-update payloads are the architecture `.zip` files (`Modesto-0.1.4-arm64.zip`, `Modesto-0.1.4-x64.zip`). Windows auto-update uses the NSIS `.exe`.
