# Modesto v1.0.0 — historical draft

The proposed 1.0 line remains experimental and was superseded by **[0.4.0 Berkeley](./v0.4.0.md)**.

The original 1.0.0 draft below claimed a finished product line and was pulled
back to 0.3.0. Keep it for history only.

## Original draft (historical)

Code + Work. The earlier draft framed Research → Work as the jump to a 1.0 product shape.

### Why 1.0.0 was proposed (and rejected for shipping)

- **Code** remains the coding IDE for repo threads.
- **Work** replaces Research as a cowork surface for local agent tasks outside Code.

That framing overstated readiness at the time. The next shipping release after 0.3.0 is **[0.4.0 Berkeley](./v0.4.0.md)**.
