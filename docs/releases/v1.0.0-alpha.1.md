# Modesto v1.0.0-alpha.1 RC

**Status: release candidate.** Semver is `1.0.0-alpha.1`. This is the first public
1.0-line build, not a finished 1.0 product.

Modesto is a local-first desktop control plane for the coding agents you already
pay for. It does not resell tokens. Codex, Claude Code, Cursor Agent, Gemini CLI,
Grok, Meta Muse Code, Factory Droid, Kilo Code, OpenCode, Pi, GitHub Copilot
(opt-in), and other compatible CLIs share one workspace: Code for shipping
software, Work for local cowork.

Source for this candidate is on
[Syphon1205/Modesto](https://github.com/Syphon1205/Modesto). License is
**AGPL-3.0-only**.

## What “RC” means here

- The product is far enough along to use and review.
- Surfaces, reliability, and packaging are still moving.
- **Signed installers are not published yet.** GitHub Latest remains the last
  shipped desktop build (`v0.3.0`) until notarized macOS, Authenticode Windows,
  and the updater manifests land.
- Do not treat this tag as a production 1.0 announcement.

## What’s new in this candidate

### Workspace

- **Chats without a project** in Code: start and send with no folder open. Work
  still requires a project.
- **Code and Work** share sidebar and composer chrome; only the job of each
  workspace changes.
- **Desktop environments:** local host, optional WSL and SSH. Threads bind to an
  environment.
- **Pop-out chat:** always-on-top window for the current thread (desktop).
- **Header usage clock:** 5-hour and weekly provider limits for the selected
  model. Modesto does not sell quota.

### Agents and providers

- Runtime-discovered providers; new CLIs show up without a hardcoded list.
- **Grok** and **Meta Muse Code** (`muse` / `muse --acp` / Muse Spark) are
  first-class and on by default.
- **GitHub Copilot CLI** is opt-in (`copilot --acp`).
- Mid-thread **handoff** starts a fresh session on the new provider and replays
  prior context.
- Isolated Git worktrees per thread, inline diffs, approvals, terminals, and
  browser previews.

### Chat and Connections

- Inline **Mermaid**, SVG graphs, and interactive HTML previews (Preview /
  Source / restart). Generated pages run in an isolated frame after the stream
  finishes.
- **Connections** for daily apps and MCP servers (Figma, Framer, Higgsfield,
  Canva, Supabase, and others). Install commands copy into chat; brand marks are
  third-party — see [THIRD_PARTY_NOTICES.md](../../THIRD_PARTY_NOTICES.md).
- Right-panel **Music** (Apple Music on Mac; Spotify and others in the in-app
  browser).
- Agent character presets, avatar customization, clearer task-dispatch errors.
- Expired local **MCP** credentials recover on the next turn; auth settings
  survive edits to an existing connection.

### Platform and license

- Client-server core: typed RPC, Effect services, Git through the real `gh` CLI.
- Secret scanning and ignore rules so local homes, `.env`, signing keys, and
  generated installers stay out of the public snapshot.
- Relabeled **AGPL-3.0-only** (MIT through v0.3.x) because of the Bible Strong
  avatar engine.

## Known issues and gaps

**Packaging**

- This RC’s GitHub draft may include checksums or **unsigned validation**
  packages only. macOS may be ad-hoc signed and **not notarized**. Windows may
  have **no Authenticode signature** (SmartScreen / Unknown Publisher even when
  company metadata says Modesto Team). Linux AppImages are unsigned.
- Do not present validation artifacts as a signed production release. Verify
  `SHA256SUMS.txt` if you sideload a validation build.
- Public CI/release workflow files are not on the public snapshot yet (token
  lacks `workflow` scope). Build/publish still runs from the private source repo.

**Install and update**

- In-app updater will not hop to 1.0 until this tag is published as GitHub
  Latest with manifests. `/releases/latest` currently points at `v0.3.0`.
- First-run copies legacy `~/.modesto` / Electron profiles once; it never
  deletes the old copy. If two Modesto instances share ports, use an isolated
  home (`MODESTO_HOME`) instead of a second default `bun run dev`.

**Product**

- **Work** is early cowork, not a finished 1.0 surface.
- Projectless send is **Code only**.
- Native macOS SwiftUI/AppKit extras (menus, pickers, deep links) are planned;
  the main workspace stays web-in-Electron.
- One HTTP snapshot transfer-budget test is still above its target; WebSocket
  budgets pass. Full interactive smoke on every OS is still pending.
- GitHub’s repo **About** license picker should be set to AGPL-3.0 so the
  download page does not keep showing MIT from older metadata.

**Expectations**

- Recovering from session restarts, reconnects, and partial streams is a core
  priority and still being hardened. Report bugs against this RC, not against
  an older desktop, once a signed build is installed.

## How to try it now

1. Clone or browse source on this repo (`bun install`, `bun run modesto:dev`).
2. Requirements: Bun 1.3.9+, Node.js 24.13.1+, at least one provider CLI.
3. Watch [Releases](https://github.com/Syphon1205/Modesto/releases) for the
   signed RC. Until then, keep using the last published installer if you need a
   notarized app.
