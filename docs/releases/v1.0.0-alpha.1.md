# Modesto 1.0.0 Aloha — Alpha Release Candidate

**Aloha** is the nickname for **1.0.0-alpha.1**. This is an **Alpha Release Candidate**
on the 1.0 line. Use it. It is not a finished 1.0.

Modesto is a local-first desktop for the coding agents you already pay for. One
workspace runs **Chat** and **Work** threads, plus Pull Requests, Agents, Tasks,
Automations, Connections, and Skills & plugins. Auth, models, and billing stay
with the CLIs you installed.

## Chat and Work

The composer is a **Chat / Work** toggle (locked after the first send).

| Mode | What it is for |
| --- | --- |
| **Chat** | Conversation-first threads. You can start and send **without opening a project**. History lives under **Chats**. |
| **Work** | Repo-scoped agent work: a project, branch, optional Git worktree, diffs, terminals, commits, and pull requests. |

Cowork tools sit beside those threads so a session can reach the browser and
connected apps without leaving Modesto: **Connections**, **Music**, **Canvas**,
**Artifacts**, and **Browser**.

## What’s in this Release Candidate

### Threads and composer

- **New Chat**, search, parallel sessions.
- Provider and model picker; permission levels **Supervised**, **Auto-accept edits**, **Auto**, **Full access**.
- Plan / Build interaction where the provider supports it.
- Mid-thread **provider handoff** with conversation, worktree, and branch carried forward.
- Checkpoints with inspect / rollback.
- Slash commands and skills in the composer.
- Attach terminal context and **Appshots**.
- **Pop out chat** — desktop always-on-top window for the current thread.
- Header **usage clock** for the selected model’s 5-hour and weekly provider limits. Modesto does not sell quota.
- Inline tool calls, diffs, approvals, Git actions, Mermaid, SVG, and interactive HTML (Preview / Source / restart).

### Sidebar

- **Pull Requests** — Reviewing / Authored; detail **Summary**, **Timeline**, **Code**.
- **Agents** — durable bot identities (including research-style starters) dispatched into threads.
- **Tasks** — Kanban **Draft / In Progress / Done**.
- **Automations** — scheduled prompts, templates, signed inbound webhooks.
- **Connections** — signed-in web apps (Figma, Framer, Slack, Linear, GitHub, Vercel, …), Adobe native apps, MCP marketplace.
- **Plugins** — **Skills & plugins**: shared `SKILL.md` packs plus Claude plugins into `~/.claude`.

### Right panel

- **Browser** and **Mobile Simulator**
- **Terminal**, **Files**, **Changes**
- **Music** — Apple Music on Mac; Spotify and others in the in-app browser
- **Canvas** — dashboards, slides, docs, spreadsheets
- **Artifacts**, **Context**, **Pull request**, **Agents**

### Desktop environments

- Local host, **WSL**, and **SSH**. Threads bind to an environment.
- Remote pair/connect routes, floating music mini-player, optional floating browser preview.

### Providers (first-class in Settings)

On by default: **Codex**, **Claude**, **Cursor**, **Gemini**, **Grok**, **Meta** (Muse Code / Muse Spark), **Kilo**.

Available: **OpenCode**, **Factory Droid**, **Pi**, **GitHub Copilot** (opt-in), **Kimi / Qwen / Poolside / Devin** (early access), **Custom ACP**, plus OpenAI-compatible **model routers**.

## Known issues (RC)

- **Work** cowork tools are real; polish and some dispatch paths (for example Kanban drag-to-run) are still landing.
- Chat-without-a-folder is **Chat** mode. Work threads still want a project.
- Session restarts, reconnects, and partial streams are still being hardened.
- Native macOS extras (menus, pickers, deep links) and **iOS** are not this desktop matrix.
- **Signed installers are not GitHub Latest yet.** Until notarized macOS / Authenticode Windows / updater manifests publish, `/releases/latest` stays on the last shipped desktop build. Sideloaded validation builds may be unsigned (Gatekeeper / SmartScreen).

## How to run it

```sh
bun install
bun run modesto:dev
```
