# Modesto v1.0.0-alpha.1 — release candidate

This candidate brings the T3 foundation migration to Modesto's public source tree.
It remains an alpha. Signed installers are pending native build validation and
release-signing credentials; this document does not announce completed publication.

## What changed

- Inline Mermaid diagrams, SVG graphs, and interactive HTML in chat, with Preview,
  Source, and restart controls. Generated code runs in an isolated frame after
  streaming finishes.
- Agent character presets, avatar customization, and clearer task dispatch errors.
- Recovery for expired local MCP credentials and preservation of authentication
  settings when editing an existing connection.
- Projectless chats, Code / Work modes, desktop environments, and Grok support.
- Source secret scanning and ignore rules for local credentials, signing material,
  databases, and generated installers.
- Connections for daily apps and MCP servers, with third-party notices for Rakazo,
  Bible Strong avatars (AGPL-3.0), OpenWork, and product brand marks.
- Relabeled the current line AGPL-3.0-only (MIT through v0.3.x).

## Planned downloads

- macOS Apple Silicon and Intel: signed and notarized DMG plus updater ZIP.
- Windows x64: NSIS installer with Modesto Team metadata. Publication requires a
  signing certificate whose verified publisher is Modesto Team.
- Linux x64: AppImage.

Build-only artifacts may be unsigned and must not be presented as signed releases.
No iOS package or ISO disk image is included in this desktop matrix.

## Publication

The destination for source and downloads is
[Syphon1205/Modesto](https://github.com/Syphon1205/Modesto).
After all signed builds pass, the release workflow publishes the production
bundle identity with `latest*.yml` and `modesto*.yml` updater feeds. Until then,
existing installations remain on the previous published release.

See [release setup](../release.md) and [secret hygiene](../secret-hygiene.md).
