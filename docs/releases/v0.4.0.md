# Modesto v0.4.0 — Berkeley

Berkeley is the redesign release produced by the latest development pass.

## Highlights

- **Workspace redesign** — rebuilt sidebar, landing page, chat tabs, composer, model picker, message timeline, menus, icons, and navigation.
- **Settings redesign** — new information architecture, search, breadcrumbs, restore controls, terminal appearance, and file-icon preferences.
- **Provider layouts** — dedicated Claude, Codex, and Cursor interfaces with matching light/dark palettes and full Modesto account controls.
- **Themes and sound** — expanded OpenCode and VS Code palette catalog plus a complete notification-sound library and playback settings.
- **Copilot workspace** — dedicated customization, preferences, palettes, skills, and session-tree experiences.
- **Simpler visual surfaces** — removed several costly 3D/animated treatments and standardized disclosure motion.
- **Better tools** — improved artifacts, inline visuals, Canvas, Markdown, Monaco, Files, and right-panel state.
- **Provider improvements** — redesigned provider/model selection, custom endpoints, router settings, Codex handling, and Gemini/ACP reliability.
- **Reliability work** — stronger approvals, handoffs, orchestration projections, reconnect behavior, and desktop IPC.
- **Independent updates** — a Modesto-owned stable feed with `modesto*.yml` manifests, while matching `latest*.yml` manifests keep older installations upgradeable.

## Upgrade compatibility

The final release bundle will contain identical updater information under both naming schemes:

- Older clients: `latest.yml`, `latest-mac.yml`, and `latest-linux.yml`.
- Current clients: `modesto.yml`, `modesto-mac.yml`, and `modesto-linux.yml`.

## Downloads

- **macOS Apple Silicon:** `Modesto-0.4.0-arm64.dmg`
- **macOS Intel:** `Modesto-0.4.0-x64.dmg`
- **Windows x64:** `Modesto-0.4.0-x64.exe`
- **Linux x64:** `Modesto-0.4.0-x86_64.AppImage`

The release bundle also includes macOS update archives, blockmaps, and updater manifests.
