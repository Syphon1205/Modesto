# Modesto v0.4.0 — New Foundation

Modesto 0.4.0 is **open source under MIT** and rebuilt on a new client-server
foundation for long-term stability. This is still an early release — useful and
evolving, not a production 1.0 claim.

## Product shape

- **Code** — coding workspace for projects, agents, diffs, terminals, and Git.
- **Work** — local cowork for tasks, Connections, sessions, browser, and
  artifacts, sharing one platform with Code.

## Highlights

- **Open source under MIT** — public on GitHub, local-first, zero telemetry,
  complete ownership.
- **New core** — typed RPC (`effect/unstable/rpc`) between client and server,
  Effect-TS services throughout, replacing the previous hand-rolled
  `WS_METHODS` dispatch.
- **Code + Work** — agent sessions, tasks, connections, diffs, and artifacts
  live together instead of forcing context switches.
- **Cross-provider handoff** — switching providers mid-conversation starts a
  fresh session on the new provider and replays prior context.
- **Tasks / Kanban** — first sidebar feature ported onto the new data model.
- **Automations & plugins** — scheduled prompts and Claude Code plugin installs
  rebuilt against this tree's conventions.
- **Kilo, for real** — a fully working driver with settings, model picker, and
  provider icon.

## Notes

- Existing projects, threads, and credentials are preserved where migration
  paths exist.
- Treat this build as an early open-source foundation release — some surfaces
  from earlier proprietary builds are still being re-ported.
- Download binaries and release notes live on
  [Syphon1205/Modesto](https://github.com/Syphon1205/Modesto/releases/tag/v0.4.0).
