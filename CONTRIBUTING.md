# Contributing to Modesto

Thanks for your interest in Modesto.

This GitHub repository is the public release and distribution home for Modesto
desktop builds. We welcome bug reports and focused feedback; large unsolicited
feature PRs are unlikely to be reviewed right now.

## How to help

1. **Report bugs** with the [Bug report](https://github.com/Syphon1205/Modesto/issues/new?template=bug_report.yml) template.
2. **Propose improvements** with the [Feature request](https://github.com/Syphon1205/Modesto/issues/new?template=feature_request.yml) template.
3. Search existing issues before opening a new one.
4. Keep reports concrete: steps to reproduce, expected vs actual behavior, OS,
   and Modesto version.

## Pull requests

We are not actively soliciting contributions. You can still open a PR, but
please keep it small and focused. Bug fixes are the most likely to be reviewed;
large feature dumps are likely to be closed.

If you do open a PR, explain:

- what changed
- why the change is needed
- how you verified it
- any compatibility or upgrade risk
