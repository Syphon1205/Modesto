# Contributing to Modesto

Thanks for your interest in Modesto.

Modesto is open source under the MIT License. This repository is the public
home for desktop builds, release notes, and the published source snapshot.
Bug reports, focused fixes, and thoughtful contributions are welcome.

## How to help

1. **Report bugs** with the [Bug report](https://github.com/Syphon1205/Modesto/issues/new?template=bug_report.yml) template.
2. **Propose improvements** with the [Feature request](https://github.com/Syphon1205/Modesto/issues/new?template=feature_request.yml) template.
3. Search existing issues before opening a new one.
4. Keep reports concrete: steps to reproduce, expected vs actual behavior, OS,
   and Modesto version.

## Pull requests

Please keep PRs small and focused. Bug fixes and clear regressions are the
most likely to be reviewed quickly; large unsolicited feature dumps are harder
to land.

If you open a PR, explain:

- what changed
- why the change is needed
- how you verified it
- any compatibility or upgrade risk
