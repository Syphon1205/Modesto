# Acknowledgements

Modesto is built by one person and uses a bunch of open source libraries.

## Project history and adapted foundation

Modesto's foundation supplies the current React application, TypeScript/Bun server, Electron shell, provider integrations, orchestration, persistence, worktrees, terminals, Git services, and WebSocket APIs. Original notices and repository history must be preserved.

## Direct dependencies

The application directly depends on projects including React, Vite, TanStack Router and Query, Effect, Electron, Bun-compatible Node libraries, Vitest, Tailwind CSS, Base UI, xterm.js, and many other packages recorded in `package.json` and `bun.lock`. Their licenses govern their respective code.

## Architectural and implementation references

The project has learned from open-source coding-agent platforms and tools including OpenAI Codex, T3 Code, OpenCode, Cline, Continue, and Codex Monitor. These references inform protocol handling, agent UX, operational safeguards, and product design. Acknowledging inspiration does not mean code was copied.

## Design references

Modesto’s compact desktop proportions and agent-first interaction model draw on established macOS interface conventions and the broader ecosystem of professional developer tools.
